# Genres by language (standing list from the user – use for ALL future generations)

Rules
- For every new theory, generate in **every genre listed for that language**, **two takes per genre: one male, one female vocal**.
  (Even where the user's prompt names one gender, e.g. "Gujarati female vocals", make both and swap the gender word.)
- Use the user's style prompt below as the opening of the ElevenLabs prompt, then add ". A song for kids learning science." and the usual singing/lyric-control lines.
- Never name real artists, films or people in a prompt. Swaps already in use:
  "AR Rahman influenced" → "modern Tamil film-score sound with layered orchestral and electronic textures";
  "Baahubali-scale cinematic sound" → "epic grand film-score scale";
  "Bulleh Shah inspired" → "inspired by classic Punjabi Sufi kafi singing".
- Devotional styles (Bhajan, Sufi, Borgeet, Bhajan-EDM) add: "The words are a science lesson: no devotional words, chants or names, only the lyric."
- Rap/hip-hop styles use the RAP line instead of the SING line.
